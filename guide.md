# How to Compile C
```
clang -Wall your_file.c -o program_name
```
- clang: c compiler
- -Wall: enable all warnings
- -o: output file name


# Another way of compilation for multiple files
```
clang -Wall file1.c file2.c -o program_name

or

gcc -Wall file1.c file2.c -o program_name
```


# How to run the file
```
./program_name
```
